# 0.5.0 release notes

Version 0.5.0 adds cubic directional punishment and cubic price-age spread
scaling to the Rust, Go, and Node.js math packages. Integer rounding and state
transitions follow `dark_pools` `update/stale-price` at
`7083e2b1ddb8aeef51f5881bf8d2431f0cf6217d` plus the declared, hashed
active-treasury reserve-sync patch. This is the combined 0.5.0 model; deployed
contracts with linear punishment still require their matching quote model.

## Behavior

- Punishment rounds the wealth ratio up to Q48 before cubing it, then rounds
  the resulting Q24 increment up. Sentinel and saturation behavior are preserved.
- The directional fee is scaled by the cubic age of the operator price before
  the output-token fee is rounded down and the caller multiplier is applied.
- Swaps persist only the fee after punishment. Age scaling does not accumulate
  in state, and operator updates reset the age origin and both directional fees.
- Quotes remain fresh through `latestUpdateBlock + blockDelay` inclusive.
  Older quotes return zero; simulations report `StalePrice` and preserve state.
- Order books price and validate fills at `maxExecutionBlock`, covering the
  age multiplier throughout the declared execution lifetime.

## Active treasury

- Treasury stays inside trading reserves; only net output and credited partner
  fees reduce the output reserve. Single-quote cubic/decay formulas are unchanged.
- Existing simulation entrypoints assume zero partner share. Partner-aware
  entrypoints are documented in the Rust, Go, and Node package READMEs.
- Rust `OrderBookState.fee_accounting` and Node `snapshot.feeAccounting` carry
  coherent router/bucket state for both simulation and preflight. Capacity
  preflight now takes `(state, config)`; Node requires the embedded fee state.
- Fee headroom is bounded by anchor-valued cumulative input caps, since retained
  treasury can earn repeated fees. Solidity vectors are schema v6, and another
  5,000 Solidity fuzz cases check partner reserve debits.

## Migration from 0.4.x

Rust and Go `PoolParams` add the maximum age multiplier, current block, latest
update block, and block delay. These values must come from one coherent
snapshot. The maximum multiplier is a Q24 `uint64`; zero supports legacy
disabled storage, and Q24 disables age scaling. Block delay is a nonzero
`uint48`.

Node.js quote parameters require string `maxDecayMultiplierX24`, `currentBlock`,
`latestUpdateBlock`, and `blockDelay`. Order-book parameters retain
`snapshotBlock` and add string `maxDecayMultiplierX24`. Rust `OrderBookState`
reads timing fields from its embedded `pool`, where `current_block` identifies
the snapshot. `effectiveFeeX24` remains the persisted fee before age scaling.

The offchain example reads `maxDecayMultiplierX24()` at the snapshot's block
hash and serializes its full uint64 domain as decimal text. Rebuild consumers
with the matching 0.5.0 package and update their snapshot initialization.

## Packages and validation

Rust, Node.js, all four npm native packages, and the examples use version 0.5.0.
The existing macOS arm64, Linux x64 glibc, Linux arm64 glibc, and Linux x64 musl
targets are retained. The minimum Rust version remains 1.90.

Schema-v6 fixtures contain 71 deterministic and 10,000 seeded-fuzz transitions
generated by the real Solidity Pool. The corpus includes a case distinguishing
Q48 rounding before cubing from exact-rational cubing, age boundaries, numeric
extremes, and atomic rollbacks. Every language package replays the same corpus.

`make publish-dry-run` checks crate and npm packaging. Build-tool installation
uses `npm ci --omit=optional`, so it works before the new native packages are
published. Native binaries and generated metadata are built and checked in
the release workflow; platform CI, including the Alpine package-install smoke
test and promised glibc floor, must pass before publication.

## Publication

After committing the prepared changes, create both tags on that same commit:

```sh
git tag v0.5.0
git tag math/go/v0.5.0
git push origin v0.5.0 math/go/v0.5.0
```

The tag push starts `.github/workflows/release.yml`. It validates versions,
runs tests, builds all native targets, tests the musl package on Alpine, and
publishes the Rust crate and npm packages using the configured repository
secrets. The Go module is versioned by `math/go/v0.5.0`.
